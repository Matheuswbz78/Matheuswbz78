Sobre mim
Sou Matheus Souza Pinto, desenvolvedor de software em Mococa, São Paulo. Sou bacharel em Ciência da Computação pela UNIFEOB e Técnico em Informática pela ETEC João Baptista de Lima Figueiredo.

Atuo no desenvolvimento web da ManejeBem / Impactools, com foco em React, JavaScript, integrações e dados. Meu trabalho passa por interfaces de atendimento, chats, perfis de usuários, formulários e dashboards — conectando regras de negócio à experiência de quem usa o sistema.

Gosto de trabalhar tanto nos detalhes da interface quanto no caminho que os dados percorrem: da integração com uma API à organização das informações e à exportação de um relatório.
- No dia a dia: componentes reutilizáveis, gerenciamento de estado, APIs REST e evolução de funcionalidades.
- Na prática: mensageria em tempo real, filtros, tabelas de análise e otimização de listas com muitos registros.
- Aprendizado contínuo: aplicações desktop com Python e interesse em TypeScript, arquitetura de software e testes automatizados.
- Interesses: desenvolvimento Full Stack, engenharia de software, Big Data e cloud.
